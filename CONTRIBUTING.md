# Contributing to Restaurant-Intel

## Branching

- `main` = stable
- `develop` = active integration
- `feature/*` = new work
- `fix/*` = bug fixes

## Commit messages

Prefer:

- `feat: ...`
- `fix: ...`
- `chore: ...`
- `refactor: ...`
- `docs: ...`
- `test: ...`

## PRs

- PRs should target `develop`
- Link issues with `Closes #123`
- Include tests where practical

## Local dev

Use the repo Makefile / Docker Compose commands if present.
